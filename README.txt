리워드 파일 올리기
1. 관리자 → REWARD → 구독 리워드의 새 등록 또는 기존 항목 수정을 선택합니다.
2. 제목·설명, 티어와 필요한 구독 개월 수를 입력합니다.
3. 공개 미리보기에는 공개해도 되는 사진 주소를 넣습니다. 실제 제공 파일과는 별개입니다.
4. 비공개 파일 업로드에서 사진 또는 ZIP/APK를 선택합니다.
5. 파일 이름·크기를 확인한 뒤 항목 저장을 누릅니다. 업로드만으로 목록에 등록되지는 않습니다.
6. 시청자는 치지직 로그인 후 조건을 충족한 리워드의 다운로드 버튼으로 받습니다.

파일 조건
- PNG, JPG/JPEG, WebP, GIF, ZIP, APK를 지원합니다.
- 파일 하나당 최대 15 MiB(15,728,640바이트)입니다. 스크린샷의 11.78MB 파일은 이 제한 안에 들어갑니다.
- ZIP/APK는 원본 그대로 저장합니다. 압축을 풀거나 APK를 실행·설치하지 않습니다.
- 파일 이름만 APK/ZIP으로 바꾼 파일은 올릴 수 없습니다. 기본 형식 검사를 통과해야 합니다.
- 기존 사진 리워드는 그대로 사용할 수 있습니다. 기존 파일에 원래 이름 정보가 없으면 제목을 다운로드 이름으로 사용합니다.
- 구독 리워드는 서버에서 현재 티어·개월 조건을, 개인 사진은 지정 수신자의 치지직 채널 ID를 확인합니다.
- 다운로드 링크는 권한 확인 후 60초 동안 유효합니다.
