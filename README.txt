얌하 홈페이지 · GitHub 업로드용 현재 작업본
포장일: 2026-10-06

올리는 방법
1. 얌하_GitHub업로드_20261006.zip의 압축을 풉니다.
2. ZIP 파일 자체가 아니라, 압축을 푼 안의 파일과 폴더를 GitHub 저장소의 기존 홈페이지 위치에 올립니다.
3. index.html이 그 위치에 바로 있어야 합니다. assets, css, js, vendor 및 각 페이지 폴더도 함께 올립니다.
4. 기존 파일은 같은 경로로 교체합니다. 이 묶음은 이미지를 포함한 전체 홈페이지 파일이며 별도 빌드 명령은 필요하지 않습니다.
5. 기존 배포가 완료되면 홈페이지와 admin/index.html을 확인합니다.

현재 상태
- 기존 원본 이미지와 승인된 메인 디자인을 유지한 현재 작업본입니다.
- 기본 프로필, 메인 사진, 채널·STORE 링크와 기존 게시물 목록을 관리자에서 편집하는 코드가 연결되어 있습니다.
- Supabase 연결 정보와 공개 클라이언트 키가 설정되어 있습니다. 관리자 계정의 비밀번호는 포함하지 않습니다.
- 사용자가 초기 SQL을 적용한 뒤 프로필 행과 안내 글 3개가 조회된 기존 기록이 있습니다. 이번 포장 때문에 SQL을 다시 실행할 필요는 없습니다. 추가 SQL 변경은 없습니다.
- 이 파일은 네이버카페 대문에 붙여넣는 HTML이나 별도 위젯이 아니라 GitHub에 올리는 홈페이지 파일입니다.

아직 완료되지 않은 범위
- 모든 페이지의 사진·문구를 관리자에서 빠짐없이 수정하도록 확장하는 작업은 미완료입니다. 고정된 제목·캡션·장식 문구 등이 남아 있습니다.
- 치지직 로그인·구독 인증·개인 방셀 파일 전달은 미연결이며, 공개 방셀 페이지는 잠금을 유지합니다.
- 이미지는 웹 주소 또는 assets/파일명 입력 방식입니다. 이미지 업로드 저장소 기능은 포함하지 않습니다.
- 운영 관리자 계정의 실제 로그인·저장·재조회 검수와 GitHub 업로드·운영 배포는 이번 전달에서 수행하지 않았습니다.

이번 포장 검수
- ZIP 무결성, 압축을 푼 실제 파일과 작업본의 바이트 일치, HTML/CSS의 로컬 링크·자산 경로, JavaScript 문법을 확인합니다.
- 미사용 편집 확장 실험 파일, 미리보기 캡처, 내부 자산 출처 목록은 업로드 묶음에서 제외합니다.
- 홈페이지의 화면 코드·데이터 계약·이미지 파일은 변경하지 않았습니다. 과거의 모의 로그인·저장 검수를 운영 검증으로 표현하지 않습니다.

SQL 파일은 GitHub 업로드 묶음에 넣지 않았습니다. 이전에 전달한 초기 설정 SQL은 별도로 보관하면 됩니다.
