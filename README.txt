얌하 홈페이지 · 관리자/리워드 연결 작업본
2026-10-06

1. GitHub에 올릴 파일
얌하_GitHub업로드_관리자_리워드_20261006.zip을 풀고 안의 파일·폴더를 기존 홈페이지 위치에 올려 주세요.
index.html, assets, css, js, vendor, 각 페이지 폴더, functions, _routes.json을 함께 교체합니다.
ZIP 파일 자체를 올리는 방식은 아닙니다. 초기 화면의 디자인과 기존 이미지 파일은 유지합니다.
GitHub와 연결된 기존 Cloudflare Pages 프로젝트에서 배포합니다. 프레임워크 없음, 사이트 루트 출력, 별도 빌드 명령 없는 구조입니다.
functions 폴더가 있어야 치지직 로그인과 비공개 파일 전달 API가 배포됩니다. GitHub Pages의 정적 호스팅만으로는 이 API가 실행되지 않습니다.

2. 관리자
주소: https://yamha.pages.dev/admin/
공통 / 메인 / 프로필 / 일정 / 공지 / STORE / REWARD / 업보 / 안내 / 노래책 탭으로 나눴습니다.
관리자 화면에서 방문자용 왼쪽 메뉴를 제거했습니다. 사이트 보기 또는 이 페이지 보기로 공개 화면을 확인합니다.
각 탭에는 해당 페이지의 사진·문구·제목·장식·안내 메시지 편집과 필요한 목록 관리가 있습니다.
메인 사진 5장은 메인 탭, 타임라인은 프로필 탭, 구독 리워드와 개인 방셀은 REWARD 탭에서 편집합니다.
STORE 주소는 STORE 탭에서 변경합니다.
화면 설정과 게시물 목록의 저장 버튼은 각각 있습니다. 저장하지 않은 수정은 표시되며 다른 탭으로 나갈 때 확인합니다.
문구의 {name}, {fanName}, {months} 등은 자동 치환 자리입니다. 일반 문장으로 바꿔도 됩니다.
기본값 복원 후 저장하면 원래 문구/장식으로 돌아갑니다. 이미지를 빈칸으로 저장하면 숨깁니다.
기존 SVG 아이콘 교체 항목은 빈칸이면 원래 아이콘을 사용합니다.
일반 이미지 편집은 웹 주소 또는 assets/파일명 방식입니다. 리워드·방셀 원본은 비공개 업로드 버튼을 사용합니다.

3. SQL
ZIP 안에 초기 SQL과 치지직 리워드 추가 SQL을 함께 넣었습니다. 두 SQL은 별도 파일로도 전달합니다.
기존 얌하_Supabase_초기설정.sql을 이미 실행했다면 다시 실행할 필요 없습니다.
치지직 기능에는 얌하_치지직_리워드_추가설정.sql을 Supabase SQL Editor에서 한 번 실행해야 합니다.
추가 SQL은 기존 프로필·안내 글·관리자 UID를 교체하지 않습니다.
SQL 파일을 GitHub에 올리는 것만으로 SQL이 실행되지는 않습니다.

4. 치지직 기능을 켜기 위해 남은 설정
현재 얌하용 치지직 앱이 아직 등록되지 않아 운영 로그인은 활성화되지 않았습니다.
치지직 앱 등록, Cloudflare 서버 환경 변수 입력, 얌하 방송인 계정 연결이 필요합니다.
동봉한 치지직 연결 안내의 순서대로 설정합니다. 로그인 리디렉션 주소는 아래와 같습니다.
https://yamha.pages.dev/api/reward/auth/callback
비밀 키와 비밀번호는 채팅·GitHub·js/config.js에 넣지 않습니다. 서버 비밀 값은 Cloudflare의 Secrets에 입력합니다.

5. 검수 범위
실제 Chrome에서 로컬 가상 서버로 관리자 로그인, 메인 사진·문구 저장 후 공개 반영, 빈칸 저장, 기본값 복원, 프로필 제목·장식 교체를 확인했습니다.
공개 9개 페이지의 모바일 화면에서 가로 넘침과 깨진 이미지를 확인했습니다.
관리자 탭 연결·옵션 보존, 구독 조건·개인 방셀 권한 검사는 가상 데이터로 검수했습니다.
추가 SQL은 로컬 PostgreSQL 환경에서 재실행·권한·비공개 저장소 정책을 검사했습니다.
운영 DB 변경, 실제 사용자 치지직 로그인, GitHub 업로드, Cloudflare 배포는 이번 파일 제작에서 실행하지 않았습니다.
