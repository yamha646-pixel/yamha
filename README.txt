적용 방법
얌하_GitHub업로드_관리자개선_20261006.zip을 풀고 안의 파일·폴더를 기존 GitHub 홈페이지 위치에 덮어 올려 주세요.
ZIP 자체를 올리지 않습니다. functions 폴더도 함께 포함해야 합니다.
기존 GitHub → Cloudflare Pages 배포가 완료되면 관리자 페이지를 Ctrl+Shift+R로 새로고침하세요.
이번 수정에는 SQL 재실행, 계정 재생성, 환경변수 변경이 필요하지 않습니다.

관리자 사용 방법
1. 공통 / 메인 / 프로필 / 일정 / 공지 / STORE / REWARD / 업보 / 안내 중 수정할 페이지를 선택합니다.
2. 각 카드의 ‘나오는 곳’ 설명을 읽고 내용이나 사진을 수정합니다.
3. ‘이 카드 저장’을 누르면 해당 카드의 변경만 저장됩니다. 다른 카드의 작성 중인 내용은 유지됩니다.
4. 페이지 제목·버튼·장식은 아래 ‘문구·사진 세부 편집’에 있습니다. 검색하면 해당 그룹이 자동으로 열립니다.
5. 공지·일정·리워드·방셀·업보·안내는 등록/수정 폼과 목록에서 관리합니다.

메인 사진은 사진별 카드에서 미리보기를 보며 바꿀 수 있습니다.
프로필은 사진·소개, 기본 정보, 성격·취향, 키워드, 플레이리스트, 방송 안내로 나눴습니다.
리워드는 내용, 수령 조건, 미리보기·원본, 공개·정렬을 나눠 설명했습니다.
관리자 노래책 탭은 없습니다. 기존 외부 노래책 주소는 프로필에서 수정할 수 있습니다.

치지직 연결 오류
방송인 연결에서 나타난 admin_required 오류는 서버가 지원하지 않는 redirect 옵션을 사용한 것이 원인이었습니다.
Cloudflare에서 동작하는 옵션으로 고치고, 외부 주소로 인증정보가 전달되는 리다이렉트는 계속 차단합니다.
로그인 확인 실패·권한 조회 실패·권한 없음은 구분하여 한국어로 표시합니다.
오류 안내는 연결 버튼 아래에 남습니다.
배포 후 REWARD → 치지직 방송인 연결을 다시 눌러 얌하 본인 계정 연결을 진행하세요.
실제 치지직 동의와 구독 판정·파일 수령 완료는 운영에서 아직 확인하지 않았습니다.

SQL 파일
기존 초기 설정·리워드 추가 설정·프로필 수정값 SQL을 ZIP에 함께 넣었습니다.
이미 실행한 초기/리워드 SQL은 이번 수정 때문에 다시 실행할 필요가 없습니다.
프로필 수정값 SQL은 이전 요청값을 DB에 저장하는 선택 파일입니다. 관리자에서 나중에 바꾼 값을 되돌릴 수 있으므로 불필요하게 반복 실행하지 마세요.
SQL 파일을 GitHub에 올리는 것만으로 실행되지는 않습니다.

검수 범위
운영 페이지에서 로그인·관리자 확인 성공 후 연결 API가 503으로 실패하는 현상을 재현했습니다.
Cloudflare workerd 로컬 실행 엔진에서 수정 전 실패와 수정 후 연결 요청 성공, 비관리자 거부, 리다이렉트 차단을 확인했습니다. 외부 서비스는 로컬 목 데이터로 검수했습니다.
Chrome 로컬 관리자에서 카드별 저장·다른 카드 초안 유지, 검색, 메인 문구 저장→공개 페이지 반영→기본값 복원, 리워드 개월 수 등록을 확인했습니다.
